# Paper (Springer LNCS)

- `main.tex`: full paper (English), Springer LNCS class `llncs.cls`
- `refs.bib`: references (bibtex, style `splncs04.bst`)
- `figures/`: result charts (PDF) generated by `figures/make_figures.py` from the real result CSVs; pipeline and lineage diagrams are TikZ inside `main.tex`
- `main.pdf`: compiled paper

Build: `pdflatex main && bibtex main && pdflatex main && pdflatex main`
Overleaf: zip this folder, then New Project > Upload Project, compiler pdfLaTeX.
